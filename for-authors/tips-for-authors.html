Tools for authors

Build a writers deck you can take anywhere.

A useful portable setup should be light, comfortable to read and quick to assemble. This three-part writers deck keeps the screen visible and the keyboard usable without turning a short writing session into a hardware project.

The screen

Xteink X4

A lightweight e-paper device that is easy on the eyes and compact enough for a small bag or coat pocket.

The keyboard

Logitech Keys-to-GO 2

A slim wireless keyboard that provides a more comfortable drafting experience than typing long passages on a phone.

A compact holder that keeps the screen upright, visible and separate from the keyboard while you draft.

Finish the setup

Make the hardware work together.

Install the latest compatible firmware and test the keyboard connection before taking the deck out. TypeSlate provides MicroSlate tools and a more detailed setup guide.

The point is not to build the most complicated portable workstation. It is to remove enough friction that ten spare minutes can become ten useful minutes of writing.
